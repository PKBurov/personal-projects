# Personal projects

Small projects and scripts, one folder each.

| Folder | What it is |
|---|---|
| `game/` | `convert.py` turns a GoldSrc (Counter-Strike 1.6) BSP map into an OBJ mesh; one sample map and its output are included. |
| `java/` | A minimal Spring Boot application with one hello endpoint. |
| `os-bash-problems/` | A short Bash practice script. |
| `powershell/` | `email_scraper.ps1` collects e-mail addresses from web pages for the countries listed in `email_nations.json` and writes them to a text file. |
| `python/` | `hashing.py`, a few lines of practice with Python dictionaries. |

Commit dates are backdated to roughly when each project was written.
